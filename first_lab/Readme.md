# Обнаружение копий приложения в локальной сети через multicast UDP

Приложение обнаруживает другие запущенные копии себя в локальной сети 
с помощью периодической рассылки heartbeat-сообщений на multicast-группу. 
Поддерживает как IPv4, так и IPv6 — протокол выбирается автоматически 
по переданному адресу группы.

## Сборка

go build -o multicast-discovery .

## Запуск

./multicast-discovery <multicast-адрес> <имя интерфейса> [порт]

### Параметры:
    multicast-адрес - адрес multicast-группы (IPv4 или IPv6)
    имя интерфейса - Имя сетевого интерфейса, через который будет идти обмен (например, `eth0`, `lo`)
    порт - UPD-порт

### Примеры запуска

IPv4:
./multicast-discovery 239.1.1.1 lo 9998

IPv6:
./multicast-discovery ff02::1234 lo 9991
